First release of BloodHound CE with the Legacy-style Explore view, built from the `legacy-view` branch (based on CE 9.8.0). Only the UI changes; the server, API and databases are standard CE, so existing CE databases open as they are. See the [README](https://github.com/edtrud385/BloodHound/tree/legacy-view#readme) for what the view adds.

## Downloads

**Docker (recommended).** Download `docker-compose.yml` and the image for your machine, then:

```bash
docker load -i bloodhound-legacy-view-image-linux-amd64.tar.gz   # or -arm64 on Apple Silicon / ARM
docker compose up -d
```

Open http://localhost:8080. On first start the admin password is printed in the log (`docker compose logs bloodhound | grep "Initial Password"`). The compose file is CE's standard example with the image swapped for `bloodhound-legacy-view`, so if you already run CE you can instead change the `image:` line in your own compose file.

The image leaves out the SharpHound and AzureHound downloads, so Download Collectors is empty; get collectors from their own release pages. This keeps the image from being flagged by antivirus and cloud-storage scanners.

**Server binary.** `bloodhound-legacy-view-<os>-<arch>.zip` holds the server with the UI built in, for Linux, macOS and Windows (amd64 and arm64). It needs PostgreSQL and Neo4j (or PostgreSQL alone with `graph_driver` set to `pg`); edit `bloodhound.config.json` and run `bloodhound -configfile bloodhound.config.json`.
